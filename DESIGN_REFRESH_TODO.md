# Digital Athlete Lab Design Refresh

This checklist tracks the proposed visual redesign. The existing site remains the production baseline until a design direction is approved.

## 1. Direction and design system

- [ ] Review the homepage mockup and collect feedback on overall tone
- [ ] Confirm the core direction: contemporary scientific editorial
- [ ] Approve the light-mode palette
- [ ] Approve the dark-mode palette
- [ ] Select heading and body typefaces
- [ ] Define a consistent spacing scale
- [ ] Define border radius, border, and shadow treatments
- [ ] Define primary, secondary, and text-link styles
- [ ] Define standard 3:2 image treatment and focal-point rules
- [ ] Document reusable design tokens in the Sass theme files

## 2. Global site shell

- [ ] Modernize the desktop navigation and active-page treatment
- [ ] Simplify and test the mobile navigation
- [ ] Increase the maximum content width where appropriate
- [ ] Improve page-header hierarchy and vertical spacing
- [ ] Redesign the footer with contact, affiliation, and key links
- [ ] Refine light/dark theme switching and colour contrast
- [ ] Standardize focus, hover, and keyboard-navigation states

## 3. Homepage

- [ ] Replace the current biography-first opening with a clear lab statement
- [ ] Add concise research-area labels
- [ ] Add primary links to projects and recent work
- [ ] Reframe the profile photograph in an editorial hero composition
- [ ] Add a featured-project section with consistent imagery
- [ ] Consolidate recent news and blog activity into a cleaner feed
- [ ] Present selected publications with less metadata and stronger hierarchy
- [ ] Reduce duplicate address and affiliation information

## 4. Projects

- [ ] Redesign cards around consistent 3:2 imagery
- [ ] Clarify category navigation and filtering
- [ ] Standardize titles and description lengths
- [ ] Replace remaining weak or duplicated artwork
- [ ] Improve project-detail typography and section spacing
- [ ] Add related projects or related publications where useful

## 5. Blog

- [ ] Redesign the post listing for stronger date and category hierarchy
- [ ] Add consistent optional thumbnails to major stories
- [ ] Improve article width, typography, headings, and pull links
- [ ] Refine related-post presentation
- [ ] Normalize tags and categories

## 6. People, publications, teaching, and CV

- [ ] Modernize profile cards and role descriptions
- [ ] Simplify publication cards and controls
- [ ] Improve teaching-page visual hierarchy
- [ ] Refine the web CV for scanning on desktop and mobile
- [ ] Apply shared card and section styles consistently

## 7. Quality and rollout

- [ ] Test at common desktop, tablet, and phone widths
- [ ] Verify colour contrast and keyboard accessibility
- [ ] Check reduced-motion behaviour
- [ ] Optimize all new images and fonts
- [ ] Run the production build, accessibility checks, and link checks
- [ ] Review a deploy preview before merging the complete redesign
- [ ] Roll out page groups incrementally, beginning with the homepage

## Decisions to make after reviewing the mockup

- [ ] Is the overall mood appropriately scientific, credible, and welcoming?
- [ ] Should the design feel warmer or more technical?
- [ ] Is the navy/cyan/coral palette right for the lab?
- [ ] Should the homepage prioritize research projects, teaching, or the lab director?
- [ ] Is the visual density comfortable, or should it be more compact?
